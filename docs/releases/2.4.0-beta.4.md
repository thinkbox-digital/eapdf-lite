EA-PDF Lite 2.4.0-beta.4 is a prerelease. It includes the browser viewer 1.9.0 and a fresh build of Desktop Viewer 0.9.0.

- Creator batch manifests now identify complete PDF generations. Failed publication restores earlier outputs, including when a worker stops mid-commit.
- Email parsing and rendering enforce tighter resource limits and keep remote content out of generated PDFs.
- Java and Python validators enforce PDF stream and child validation limits. Java stages each run’s reports before publishing them.
- Release acceptance checks all six EML conversion profiles, checks representative Java and Python validation results, and scans runtime dependency inventories.

Use Java 21 or later.
